Getting started

Alpine runs your scripts in an embedded Lua 5.4 VM. Each script gets its own state and its own thread, so one script cannot stall or break another.

Your first script

Open the Lua panel, paste this and press Ctrl+Enter.

hook.register("onPaint", function()
    local w, h = screen.size()
    draw.text_outlined("hello from alpine", w / 2 - 60, 40, color.white)
end)

The editor

Action What it does
Ctrl+Enter Run the script in the current tab. Running again reloads it.
Ctrl+S Save to the tab's file. If the script is running it reloads.
Shift+wheel Pan sideways when a line is wider than the editor.
execute / reload The button changes name while the script is loaded.
unload Stops the script and removes its drawings, tabs and widgets.

A tab that was opened from or saved to a file is watched. When the file changes on disk the tab refreshes, and a running script reloads. Unsaved edits in the panel are never overwritten.

When a script fails, the line is marked in red, the message is shown next to the code and in the status bar, and the tab's dot turns red.

Which names can I use?

Alpine understands three styles. You can mix them in one script.

Style Example Page
Native draw.rect_filled(x, y, w, h, color.red) Drawing, Menu UI, Input
Serotonin draw.RectFilled(x, y, w, h, Color3.new(1, 0, 0)) Serotonin scripts
Matcha Drawing.new("Square"), UI.AddTab(...) Matcha scripts

Luau syntax such as +=, continue and type annotations is accepted. See Luau support.

Files

file, config, readfile and writefile all work inside one folder next to the program, called files. Paths are relative to it. .. and drive letters are rejected.

Scripts and lifecycle

How a script runs

  1. The script body runs once, as a task. It may call task.wait, so a top-level while true do ... task.wait() end loop is fine.
  2. After the body finishes or pauses for the first time, the script counts as loaded and onLoad fires.
  3. onFrame fires at the script's tick rate. onPaint fires once per rendered frame.
  4. On unload, onUnload fires and everything the script created is removed.
time.set_rate(60)

hook.register("onFrame", function(dt)
end)

hook.register("onPaint", function(dt)
end)

hook.register("onUnload", function()
end)

Draw calls only have an effect inside onPaint.

Hooks

Function Description
hook.register(name, fn) Add a callback.
hook.unregister(name, fn) Remove it.
hook.count(name) Number of callbacks on an event.
Event Arguments Fires
onFrame dt At the tick rate (default 144 per second).
onPaint dt Every rendered frame.
onLoad Once, after the body ran.
onUnload Before the script is removed.
onMenuOpen, onMenuClose When the menu opens or closes.

cheat.register accepts the same events plus the Serotonin names onUpdate, onSlowUpdate, shutdown and newPlace.

A callback that raises an error is reported once and then removed. The rest of the script keeps running.

Tasks

Function Description
task.spawn(fn, ...) Run fn now as a new task. Returns the thread.
task.defer(fn, ...) Run it on the next tick.
task.delay(seconds, fn, ...) Run it later.
task.wait(seconds) Pause the current task. Returns the time waited.
task.cancel(thread) Stop a task.
task.count() Tasks currently waiting.

wait, spawn and delay are the same functions without the prefix.

task.wait cannot be called directly inside a hook callback. Wrap the work in task.spawn.

task.spawn(function()
    while true do
        task.wait(1)
        print("one second passed")
    end
end)

Time and screen

Function Returns

time.clock() Steady clock in seconds. Use it to measure elapsed time.
time.unix() Wall-clock time in seconds since 1970.
time.dt() Seconds since the last paint.
time.frame() Frame counter.
time.rate(), time.set_rate(hz) Tick rate, 0 to 1000. 0 ticks once per rendered frame.
time.paint_ms() How long the last onPaint took.

Script and logging

Function Description

log.good(...) Green line.

Limits

A single callback or task step may run about 50 million VM instructions. After that it is stopped with an error, so an accidental infinite loop cannot freeze the script thread. A script that produces ten errors within one second is unloaded.

Call these inside onPaint. Coordinates are pixels from the top-left of the game window.

Native functions take a packed colour made with color.rgba. The PascalCase versions (draw.Line, draw.RectFilled, ...) take a Color3 instead, see Serotonin scripts.

Menu UI

Scripts can add their own tabs to the main menu or open separate panels. Widgets keep their values when the script is reloaded.

Building a tab

local tab = ui.tab("My script")
local box = tab:group("Options", 1)

local enabled = box:toggle("Enabled", true)
local range = box:slider_int("Range", 300, 0, 1000, " st")
local mode = box:combo("Mode", { "Box", "Corner", "None" }, 1)
local key = box:keybind("Hold key", 0x46)

enabled:on_change(function(value) print("enabled is now", value) end)

hook.register("onFrame", function()
    if enabled:get() and key:active() then
    end
end)

Input

Keys are Windows virtual-key codes (0x46 is F) or names such as "f", "space", "lshift", "f5", "leftmouse". Names are not case sensitive.

Luau support

The VM is Lua 5.4. Scripts written for Roblox's Luau are translated when they load. Line numbers stay the same, so errors point at the right line.

Syntax that is translated

Luau Example
Compound assignment count += 1, text ..= "!"
continue if not ok then continue end

Behaviour matched to Luau

  • tostring(5.0) and print(5.0) give 5.
  • string.format("%d", 3.7) gives 3 instead of an error.
  • math.random, string.sub and string.rep accept fractional numbers.

Known differences

  • Joining a fractional-type number with .. still shows .0, for example "HP: " .. 100.0 gives HP: 100.0. Use tostring, string.format or a backtick string.
  • continue inside repeat ... until fails if a local is declared between the continue and the until.
  • An if used as a value cannot use ... from the surrounding function.
  • error raises a real error, as in standard Lua.

Luau and Roblox style

local RunService = game:GetService("RunService")

local label = Drawing.new("Text")
label.Position = Vector2.new(20, 200)
label.Outline = true
label.Visible = true

local frames = 0
RunService.RenderStepped:Connect(function(dt: number)
    frames += 1
    if frames % 2 == 0 then return end
    label.Text = `frame {frames}, {math.floor(1 / math.max(dt, 0.001))} fps`
    label.Color = if frames % 120 < 60 then Color3.new(1, 1, 1) else Color3.fromRGB(120, 200, 255)
end)
